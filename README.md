# Karoliny

Osobna aplikacja PWA bazujaca na poprzednim planie: jadlospis, woda, zakupy, przypomnienia, wlasne posilki i przepisy z dodatkami.

## Wytyczne Karoliny

- Insulinoopornosc: malo weglowodanow, niski ladunek glikemiczny, brak cukru.
- Domyslne cele startowe: 1600 kcal, 120 g bialka, 90 g wegli, 75 g tluszczu. Limit kcal zostaje edytowalny w aplikacji.
- Baza opiera sie na chudym bialku, warzywach nieskrobiowych, malych porcjach kaszy gryczanej/straczkow i produktach bez dodatku cukru.
- Wykluczone: mleko, jogurt naturalny, kefir, skyr, wiekszosc nabialu, kawa, Nootri, brukselka, owsianki, cytrusy, tluste miesa, pieczony kalafior.
- Dozwolony nabial: serek homogenizowany bez cukru i ser bialy/twarog.

## Publikacja na GitHub Pages

1. Utworz nowe publiczne repozytorium na GitHubie, np. `karoliny`.
2. Wgraj wszystkie pliki z tego folderu do glownego katalogu repozytorium.
3. Wejdz w `Settings` -> `Pages`.
4. W `Build and deployment` wybierz `Deploy from a branch`.
5. Wybierz branch `main` oraz folder `/root`.
6. Zapisz i poczekaj na adres strony.

Adres bedzie wygladal podobnie do:

`https://twoj-login.github.io/karoliny/`

Na telefonie otworz ten adres i dodaj aplikacje do ekranu glownego.
